- The idea, the feature briefs in `docs/briefs/`, the starter steering files, hook definitions, custom agent definitions, chamber presets and pass marks were prepared in a planning session with an AI assistant (Claude) on 2026-11-10, before any product code existed. - Everything under `.kiro/specs/`, and all product code and tests in `packages/` and `apps/`, were produced in Kiro from those briefs.
